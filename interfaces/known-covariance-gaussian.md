# 既知共分散Gaussian尤度の参照API

段階100。`vsora_correlator.gaussian_likelihood` をsource実行とwheel導入で共用する。既知モデルの参照計算であり、現在のClosure＋RMLの画像化経路へはまだ接続していない。

## 1. 対象と前提

ある時刻・周波数における全局の複素電圧を列ベクトル `x_m ∈ C^n` とする。以下を仮定する。

- 平均は既知の0。各標本の平均をデータから推定して引く処理は含まない。
- 各ベクトルはproper complex Gaussian分布に従う。Gaussianの場合、擬共分散 `E[x x^T]` が0なら、ここで扱う円対称な密度を使える。
- 行方向の `M` 標本は独立で、すべて同じ共分散 `C=E[x x^H]` を持つ。
- 全局がまったく同じ標本集合を持つ。局・基線・三角形ごとに異なる標本を混ぜない。
- 比較する `C0` と `C1`、独立標本数 `M` は既知である。

このGaussian密度の定義は [Hankin (2015), 式(2)](https://journal.r-project.org/articles/RJ-2015-006/) に基づく。電波干渉計の共分散モデルに対する対数尤度の形は [Leshem and van der Veen (2000), 式(34)](https://arxiv.org/pdf/astro-ph/0008239) に対応する。以下のAPI・数値アルゴリズムと受け入れ条件は本プロジェクトの設計である。

実RTL-SDRの量子化、I/Q不均衡、RFI、LO変動、実効独立標本数を、このAPIが検査・解決するわけではない。入力配列だけでは標本の独立性や観測上の共通性も証明できない。

## 2. API

```python
from vsora_correlator.gaussian_likelihood import (
    sample_second_moment, gaussian_nll, gaussian_log_likelihood_ratio,
)

# voltage.shape == (M, n)、全行で全局の値が存在すること。
S = sample_second_moment(voltage)
q0 = gaussian_nll(C0, S, len(voltage))
log_ratio = gaussian_log_likelihood_ratio(C0, C1, S, len(voltage))
# log_ratio > 0 なら、同じ標本は既知候補C1に対してより尤もらしい。
```

| 関数 | 入力 | 出力 |
|---|---|---|
| `sample_second_moment(voltage)` | 完全な有限数値配列 `[M,n]`、M,nとも1以上 | `S=Σ x_m x_m^H / M`、complex128配列 `[n,n]` |
| `gaussian_nll(C,S,M)` | 同じ大きさの行列、正定値C、半正定値S、整数M | `M[logdet C + tr(C⁻¹ S)]`、float |
| `gaussian_log_likelihood_ratio(C0,C1,S,M)` | 共通S/Mに対する二つの既知C | `log L(C1) − log L(C0)`、float |

`H` は共役転置。配列の各行は列ベクトルの転置として保存するため、Sの計算の向きは `voltage.T @ voltage.conj() / M` となる。`voltage.conj().T @ voltage` とは複素共役の向きが異なる。

Sは平均を引かない2次モーメントで、分母はM。分母M−1の不偏共分散へ置き換えない。`M<n` の場合の特異なSや、すべて0のSも計算対象である。Sだけを渡すAPIは、Sの由来やMとの階数整合性まで検査しない。

qは電圧標本の負の対数尤度から、Cに依存しない `M n log π` を除いた値。S自体の正規化された確率密度ではない。連続密度なのでqは負にもなり、0〜1の確率ではない。電圧の単位を変えるとqには定数が加わるが、共通の単位で比較する対数尤度比は変わらない。

## 3. 数値計算と入力拒否

- float64 / complex128へ変換する。文字列、bool配列、masked array、空配列、NaN/Infは拒否する。非0成分が変換や規格化で0に消える場合も拒否する。
- 行列はHermitianを要求する。最大の実部・虚部成分で規格化した行列について、Hermitian差の許容量は `64 ε n`。許容範囲内の差だけを対称化する。εはfloat64の機械イプシロン。
- Cの規格化固有値は `λmin > 64 ε n λmax` を要求する。数学的に正定値でも、float64で数値的に解けない条件では拒否する。
- Sの規格化固有値は `λmin >= −64 ε n max(1, ||S_normalized||₂)` を要求する。丸め誤差の範囲を認めるが、固有値を0へ切り上げる修正は行わない。
- Mはbool以外の整数、`1 <= M <= 2**53`。独立性の実証やFFT件数からの実効M推定は呼び出し側の課題である。
- C0で白色化した相対共分散についても `min(1+d) > 64 ε n max(1,max(1+d))` を要求する。極端な候補間の尺度差、途中計算や最終値がfloat64の範囲を超える場合は拒否する。
- 不正入力や検出した数値範囲外は `ValueError`。入力を変更せず、正則化や受信機パラメータの推定で自動的に補わない。

qはCholesky分解と三角行列の連立方程式で計算し、逆行列を明示的に作らない。

対数尤度比は、二つの大きなqを引く計算を避ける。`C0=L L^H`、`D=L⁻¹(C1−C0)L⁻H=U diag(d) U^H`、`T=L⁻¹ S L⁻H` とし、`t=diag(U^H T U)` とおくと、各固有方向の寄与は次の形になる。

```
log L(C1) − log L(C0)
 = M Σ_i [ d_i/(1+d_i) (t_i−1)
           + d_i/(1+d_i) − log(1+d_i) ]
```

この式はGaussian密度からの本プロジェクトでの式変形。実装では `t_i−1` を計算するために、`L⁻¹(S−C0)L⁻H` を先に作って回転する。Tを回転した後で1を引く丸め誤差を避ける。小さいdでは最後の二項にも桁落ちがあるため、`|d|<0.001` では2次〜8次の級数 `Σ_{k=2..8} (−1)^(k+1) (k−1)/k d^k` を使う。それ以外では `log1p(d)` を使う。非0の主要な2次項がfloat64で0に消える場合は拒否する。等しい有効なC0/C1は、SとMも検査した後、厳密に0を返す。

この実装は任意の悪条件行列に対する高精度保証ではない。上の受け入れ条件と、段階レポートに記載した検証条件を適用範囲とする。

## 4. 実運用への接続で必要なこと

既存raw-v2の三角形ごとの共通標本と電力だけでは、全局共通のSを得たことにならない。同じ標本数というだけでも不十分。共通標本の来歴を保証するproducerが必要である。

局gainやSEFDが未知なら、天空モデルからCを決めるためにそれらを推定するか、尤度から消去・周辺化する設計が必要になる。LOが区間内で動く場合には、固定Cの仮定も見直す必要がある。既知の可逆な局変換をC/Sの両方へ与えたときの比の不変性は、未知の局変換を推定できた証明にはならない。

この参照APIの値をそのまま現在のRMLへ入れて、低SNRでの画像尤度が完成したと解釈しない。既存U3の標本ごとの高次積の実現値を、Sだけから再現する用途にも使わない。
