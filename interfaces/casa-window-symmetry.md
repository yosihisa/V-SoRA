# 既知天空の有限電圧とwindow虚部の対称性

段階087の模擬実験。観測power正規化U₃（段階085）の虚部を、全window符号反転（段階086）へ渡す。実機・未知LO推定・画像復元のAPIではない。

## 入出力

```bash
python -m vsora_simulator.casa_window_symmetry --profile full --output new-result
```

同梱設定とCas A参照画像だけで実行する。既存出力先は拒否する。各条件を`cases/`へ保存し、全条件終了後に`summary.json`と図を作る。失敗条件もJSONへ残し、成功集計は作らない。`--profile smoke`は3条件・各16反復・16モードの動作確認で、統計検証には数えない。

Python入口は`case_plan(profile)`、`experiment(case)`、`run(output,profile)`。正式計画は結果を見る前に固定した53条件。

| 条件群 | 設定 | 反復数 |
|---|---|---|
| 短標本36条件 | M128/512、最大25/100/600m、receiver SEFD1000/10000/約585966Jy、点源/Cas A | 各1024 |
| 長標本10条件 | M19200、最大100/600m、SEFD1000/約585966Jy、点源/Cas A。さらに600m・10000Jyの両天空 | 各256 |
| 対照7条件 | M512、8window、600m。無信号、局別SEFDの点源、等輝度/非等輝度二点、二次位相、真値逆位相、window複製 | 各1024 |

Q=8、56三角形を一緒に処理する。M19200は理想的な独立複素モード数=64kHz×0.3秒の仮定例で、実際のADC・FFT・FIRの独立標本数ではない。M128/512から実観測時間を定めない。全windowは同じ固定uvを使う。

## 電圧モデルと必要な仮定

共分散Sは既知天空の信号・自己雑音とreceiver背景を含む。検定へ渡すのは各windowの`Im[U₃/(P_i P_j P_k)]`のみで、真のS、SEFD、天空、誤差σは渡さない。

ここで複素電圧は実部と虚部を持つ標本、powerはその絶対値の二乗の平均である。U₃は異なる標本番号の三基線積を平均する量。局gainは受信機が掛ける振幅倍率と位相回転を複素数で表したものになる。properな平均0の複素Gaussianは、擬共分散`E[x xᵀ]=0`を持ち、全体位相の回転に分布が不変である。共役で同じ分布になる説明には、さらに下記のSの実行列化が必要になる。

Sが一定の局位相を外すと実行列になるproper Gaussianモデルでは、その位相を外した電圧は共役にしても同じ分布を持つ。正規化U₃は電圧の共役で共役になり、虚部は反転する。また区間内で一定の非零局gainは相殺される。このため虚部ベクトルが中央対称となり、windowを独立に生成すれば各行反転の同時分布不変性が成り立つ。比の不偏性や三角形間の独立性は必要としない。

点源、無信号、局別SEFDの点源はこの条件を満たす。等輝度二点も二つの応答位相の平均を外すと実共分散になる。広がった天体を必ず棄却する検定ではない。実共分散への変換残差は生成モデルの確認値で、実観測から未知真値を得た結果ではない。

正式計画で帰無モデルを支持する条件だけ、棄却割合≤α+6√[α(1−α)/反復数]を固定MC確認に使う。α=0.01/0.05。有限乱数実験は理論の証明ではない。Cas A等の棄却割合は合否に使わず全て保存する。多数条件の最小pを一つの全体的な有意水準と解釈しない。

## 対照と制約

- 二次位相は既知の人工的な局別時間変化で、点源でも十分条件を失い得る。真値逆位相は同じ有限電圧と比較するが、未知LOの推定成功ではない。
- 線形LO差だけでも必ず棄却するとは仮定しない。時間反転と共役・一定局位相によって対称性が残る場合があり、対称性の保持もcoherence損失が無いことを保証しない。
- 同じwindowを8回複製すると、周辺対称性があっても行別反転の仮定を失う。この対照では最小p=2/256を確認する。実観測の重複・フィルタ相関の影響量ではない。
- gainと共役変換の照合は各条件の最初の4反復。windowを共役にすると観測順位は変わるため、その前後でpの一致は要求しない。

参照形状は2017年1378/1750MHz画像由来の代理モデル。総flux1000Jy、位置・時刻・SEFDは仮定で、visibilityを段階081の固定3配置と照合する。棄却はCas Aの存在・広がり・画像品質の証明ではなく、非棄却も点源の証明ではない。低SNR画像尤度、実際の独立性、量子化、RFI、未知LO、主ビーム、実機画像は対象外。
