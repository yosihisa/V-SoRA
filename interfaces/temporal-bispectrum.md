# 時間相関と三基線積のモデル検証

## 何を確かめるか

三基線の積（bispectrum）は、三つのアンテナの組で作る複素数です。その角度がClosure phaseです。段階053のU₃は、三つの基線について異なる標本番号を選び、共通の標本を使う偏りを除きます。しかし「番号が違う」と「雑音が独立」は別の条件です。フィルターが同じ入力を使うと、近くの出力には時間相関が残ります。

このAPIは、天体信号がゼロで、局ごとの受信機雑音は互いに独立な既知proper Gaussianモデルを対象とします。観測の未知共分散を推定する機能ではありません。

## 入力とAPI

`vsora_simulator.bispectrum_temporal`の実験用APIです。

| 関数 | 入力 | 出力 |
|---|---|---|
| `white_filter_temporal_covariance(h,H,M)` | 有限係数h、raw標本間隔H、出力数M | `K[a,b]=E[y[a] conj(y[b])]` |
| `temporal_receiver_bispectrum_mean(K)` | 3局それぞれの既知時間共分散`[3,M,M]` | 通常積とU₃の複素期待値、仮定・未検証flag |

Mは3〜256、hは1〜4096係数、Hは正整数。有限・Hermitian・半正定値を数値許容差付きで確認し、masked入力を拒否します。入力Kを変更しません。PSDの数値確認だけでは、未知の実データをこのモデルへ適用してよいとは判断できません。

白色の単位分散入力xから、`y[a]=Σ_r h[r] x[aH+r]`を作ると、正の時刻差dの共分散は`Σ_r h[r] conj(h[r+dH])`です。Toeplitz行列として全時刻のKを作ります。既存のFIR・補間・FFT係数との対応は、直接作用素Aの`A Aᴴ`と照合しています。

## 三基線積の期待値

局i,j,kの時間共分散をK₀,K₁,K₂とします。異なる局は独立で、天体の相互相関はゼロです。基線の向きは`i→j→k→i`です。

三つの基線標本a,b,cを掛けた期待値は、

`E[z₁[a] z₂[b] z₃[c]] = K₀[a,c] K₁[b,a] K₂[c,b]`

となります。全添字の総和をN、a=bの総和をNab、a=cをNac、b=cをNbc、a=b=cをNabcとすると、

- `E[通常積] = N / M³`
- `E[U₃] = (N − Nab − Nac − Nbc + 2 Nabc) / [M(M−1)(M−2)]`
- `N = tr(K₀ K₂ K₁)`
- `Nab = Σ_a K₁[a,a] (K₀ K₂)[a,a]`
- `Nac = Σ_a K₀[a,a] (K₂ K₁)[a,a]`
- `Nbc = Σ_a K₂[a,a] (K₁ K₀)[a,a]`
- `Nabc = Σ_a K₀[a,a] K₁[a,a] K₂[a,a]`

これらはこのリポジトリで局独立性と添字の包除から導出し、小Mの全列挙で検証した式です。三局に同じK、対角が一定r₀なら、U₃の分子は`tr(K³) − 3 r₀ tr(K²) + 2 M r₀³`です。白色K=IではU₃の期待値はゼロ、通常積は1/M²です。時間相関を持つKでは、異なる添字からも偏りが残り得ます。

## 固定モデルの結果

5条件×8192試行です。数値は全てモデル単位で、受信機の実測値ではありません。各局の出力雑音powerを1に正規化しています。

| 条件 | 保持数 | 通常積の理論平均（実部） | U₃の理論平均（実部） |
|---|---:|---:|---:|
| 白色 | 128 | 6.103516e−5 | 0 |
| 65標本の平均、8標本おき | 128 | 2.175305e−3 | 1.344972e−3 |
| 基準FFT32、中央ch、補間δ=0.25 | 128 | 6.103784e−5 | 約4.97e−15 |
| 平均の出力を9個おき | 15 | 4.444444e−3 | 0 |
| 基準FFT出力を5個おき | 26 | 1.479290e−3 | 0 |

実虚平均は全条件で事前の6 MC SE基準に整合しました。長い平均のU₃偏りはこの試行数でも分解できます。基準FFTの極小のモデル偏りは、この試行数では分解できません。微小値は浮動小数点の差の影響も受けるため、実機への誤差上限には使いません。

## 間引きの意味と制約

有限係数の入力範囲が重ならない間隔を使うと、白色proper Gaussian入力・固定係数の仮定では出力共分散が対角になります。平均の例では128から15、基準FFTでは128から26標本へ減ります。ゼロ源モデルでもU₃の散らばりが大きくなるため、実機に一律の間引きを推奨する結果ではありません。通常積の白色バイアスも、Mを減らすと大きくなります。

Monte Carloは既知KのCholesky分解からGaussian係数を生成します。物理的なraw畳み込み・量子化・VDIF処理を行った実験とは区別します。実際の受信機で入力が色付き、局間相関、時間変化するgain、時計変動がある場合、入力範囲を離すだけでは独立性を保証できません。現在の相関器統計とRMLの重み・採否は変更していません。
