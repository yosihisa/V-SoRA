# 独立な短積分U₃の等重み平均

実験API：`vsora_simulator.bispectrum_average.gaussian_averaged_bispectrum_moments(S, M, Q, triangles=None)`。

- S：既知の局電圧共分散、3〜8局、有限・Hermitian・半正定値。
- M：各短積分内の独立標本数、厳密な整数3〜100万。
- Q：独立で同じ平均・共分散を持つ短積分の数、厳密な整数1〜100万。
- 各短積分の電圧は平均0のproper Gaussian、局gainは積分内一定と仮定します。

各窓のU₃を `U(q)` とすると、`Ū = Σ U(q) / Q` です。平均は単一窓と同じで、複素共分散Γ、擬共分散Π、全実共分散Cはそれぞれ1/Qになります。[単一窓の有限Mの式](joint-bispectrum-moments.md)を使います。

M×Q個の電圧をまとめて一つのU₃を計算する方法とは異なります。例えば天体なし・局power1では、平均の複素分散は `1/[Q M(M−1)(M−2)]` で、一括U₃の `1/[(QM)(QM−1)(QM−2)]` とは一致しません。

## Gaussian参照領域の診断

`workflows.bispectrum_average_validation` は既知Sの5モデルを各8192試行生成し、Q=1/4/16/64を比較します。大きいQまで作った同じ試行の先頭窓を共有するため、Q間の比較は統計的に対応があります。試行を観測値で選別しません。

実部・虚部の残差を、既知C/Qの非零固有空間で白色化します。固有値の相対許容値は10⁻¹²です。共分散が特異なモデルでは、捨てた方向の残差が丸め範囲内であることも検査します。白色化した二乗距離をGaussianのカイ二乗分位点と比較します。分位点は[SciPy公式chi2](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.chi2.html)の`ppf`で計算します。

その領域に入った試行割合を「包含率」と呼びます。95%・99%はGaussianなら期待する参照値であり、U₃に保証した値ではありません。同じ自由度のGaussian乱数を対照として生成します。

合格基準は、平均と全実共分散の6 Monte Carlo標準誤差内、残差の支持空間、Gaussian対照の参照包含率です。**U₃の包含率が95%・99%になることは合格条件にしません。** 差も検証結果として保存します。失敗時には`failed_validation`のJSONと図を残して例外を返します。

[Blackburnほか（2020）](https://arxiv.org/html/1910.02062v2)は低SNRでのClosureの非線形雑音とGaussian近似の適用条件を扱います。ここで実装したU₃の等重み平均の尤度を同論文が保証する、とは扱いません。

## 適用できない事項

未知の局gain振幅の変化、空間周波数・天体・帯域の変化、FFTや窓の時間相関、ADC/FIR、品質選別、同じデータによる時計補正、標本power正規化、観測共分散の推定、実機の信頼区間、画像品質は未検証です。Qを観測秒数へ直接換算しません。現在のRMLの尤度・重みは変更しません。
