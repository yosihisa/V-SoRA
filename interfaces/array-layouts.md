# 仮想局配置と最大基線長

`vsora_observation.layouts.reference_layout(stations, kind, maximum_baseline_m=600)` は、4/8局、spread/line/ringの仮想ENU座標を返す。最大基線長は**全局間距離の最大値**であり、基準局からの最長距離・最大半径ではない。共通APIとGUIは参照範囲10〜600mを扱う。

直線は両端の間隔、円周は直径、分散配置は固定の相対形状を指定最大距離へ規格化する。全6既定配置は段階078の導入済みGUIから保存した600m座標とバイト一致を確認する。保存済みJSONを独立した比較値として使い、変更後のGUIの関数だけを比較元にしない。

模擬観測・Closure＋RML・感度計画の受付モデルへ `maximum_baseline_m` を追加し、600mを既定値とする。保存する観測configの各局ENU座標に反映する。未知の実観測の位置を縮小する処理ではない。VDIF解析にはmanifestにある実入力の局位置を使う。

仮想site、1.42GHz、参照画像・総fluxの仮定、短積分、既存Gaussian雑音近似とLO補正済みの条件は各入口の規約に従う。基線を短くすると相関が強くても、細かい形状を測れるという保証はない。今回の配置はアンテナ寸法・局間距離の下限・相互結合・敷地・beamを評価しない。実機に使う配置の承認や最適化結果として扱わない。
