# 三基線積U₃のゼロ源分散と短積分の条件付き感度

## 平均の偏りと、散らばりを分ける

平均の偏りを除いても、一回の三基線の積には大きな雑音が残ることがあります。段階053のU₃について、天体がない・各局の雑音は単位power・局間と標本間は独立なproper Gaussianという既知モデルで、その散らばりを計算します。実機の雑音の大きさを測った結果ではありません。

## ゼロ源モデルでの正確な式

M個の電圧標本から、異なる標本a,b,cを使う三基線積を作ります。その項を

`T(a,b,c) = x_i[a] conj(x_i[c]) x_j[b] conj(x_j[a]) x_k[c] conj(x_k[b])`

と書くと、U₃はこの項を順序付き異添字のM(M−1)(M−2)通りで平均したものです。

局間独立性とGaussianの二次モーメントの組合せから、`E[T(a,b,c) conj(T(A,B,C))]`は、a=A,b=B,c=Cのときだけ1となります。`E[T(a,b,c) T(A,B,C)]`は、異添字条件と同時に満たせず0です。したがって、

- `E[U₃]=0`
- `E[|U₃|²] = 1 / [M(M−1)(M−2)]`（複素分散）
- `E[U₃²]=0`（擬共分散）
- `Var(Re U₃)=Var(Im U₃)=1 / [2 M(M−1)(M−2)]`
- 実部と虚部の共分散は0

となります。式はこのリポジトリで局ごとのGaussian添字の組合せから導出し、小Mの全順序付き組合せと独立に照合しました。無相関が分布全体の独立性を意味するわけではありません。

## 既知の天体モデルに対する条件付きの尺度

三辺の、局powerで正規化した既知相関係数の絶対値をρ₁,ρ₂,ρ₃とすると、既知モデルのbispectrum絶対値はρ₁ρ₂ρ₃です。この既知値をゼロ源モデルの実部/虚部σで割った尺度を

`SNR_null = ρ₁ρ₂ρ₃ sqrt(2 M(M−1)(M−2))`

と定義します。天体があると分散や擬共分散も変わるため、これは天体ありの厳密なSNRでも、検出確率や角度の信頼区間でもありません。

同じ天体bispectrum・同じ正規化で、Q個の窓の雑音が独立なら、平均のゼロ源σは1/√Qへ減ります。目標尺度Kに達する条件付き窓数は`ceil[(K/SNR_null)²]`です。ゼロの辺があると有限個では到達しないとします。複数の三角形や周波数channelを自動で独立とみなして数を足しません。

## API

`vsora_simulator.bispectrum_sensitivity.null_bispectrum_variance(M)`はゼロ源モデルの正確な式を返します。`conditional_bispectrum_plan(M,rho,windows,target_snr,window_seconds)`は、M・三辺の既知ρ・Q・目標尺度・0.1〜3秒から条件付きの値を計算します。

Mは3〜100万の整数で、確認済みの独立電圧標本数を想定した入力です。実FFTや帯域×積分時間から、実機の独立数を確認せず自動決定する機能ではありません。ρは実数の絶対値3個で0以上1未満。どの三基線位相を選んでも半正定値な局相関行列にならない絶対値の組を拒否します。絶対値だけから実際のClosure phaseや天体ありの雑音共分散が決まるわけではありません。現在の値は既知モデル用で、未知観測から正確なρや局gainを校正するAPIではありません。

## 短い積分と弱い三辺の代償

三辺が同じρなら信号尺度はρ³に比例します。各辺を2倍にすると三基線積は8倍となり、ゼロ源σを用いる必要窓数は約1/64になります。独立標本数Mが十分大きい場合のσはM^(-3/2)です。短積分や間引きでMが減ると、その分だけ三次統計の散らばりが増えます。

比較workflowでは1000Jyの点源、局ごとに同じSEFD、64kHz×0.1/0.3/1/3秒のMを仮定します。これは最良に近い既知モデルの比較です。拡がったCas Aの長い基線の相関fluxを計算した結果ではありません。実FFTの独立性も確認した値ではありません。モデル内の5個おきの保持数を比較しますが、実機の間引き推奨ではありません。

長時間に窓を増やすと地球回転でuvが変わります。実際のCas Aで同じ三基線積を何時間も無条件に平均してよいとは判断できません。局gain振幅・周波数ごとのbandpass・正規化の推定誤差・時計の変化も別に扱う必要があります。同じ電圧からrateやgainを推定して補正する場合、その推定への依存も独立標本の仮定を変えます。

現行の相関器統計とRMLの入力・雑音モデル・SNR条件は変更しません。ゼロ源でのGaussian検証、天体ありの雑音尤度の検証、未知観測からの画像復元を段階ごとに区別します。
