# 既知の共通時間相関と三次統計の平均

## 対象

`common_temporal_bispectrum_mean(S, K, triangles=None)` は、次の共分散を持つ平均0のproper Gaussian電圧を仮定する。

```text
E[x_i(t) conj(x_j(u))] = S[i,j] K[t,u]
```

Sは3〜8局の既知の局共分散、Kは3〜256出力の既知の共通時間共分散である。全局に共通のKを使う分離可能なモデルに限る。Kの対角は正の一定値r₀を要求し、数値許容値はKの最大成分の10⁻¹²。入力を観測値から推定しない。

実際の局ごとに異なる補間・時計・フィルタ、時間変化するgain、品質マスク、同じ記録で推定したLO補正は含まない。Gaussian係数をKから直接生成する実験は、ADC・FIR・VDIFを物理的に処理した実験とは区別する。

反復実験のSは、Iを4局単位行列、Jを全成分1の行列として、I、I+0.001J、I+0.1J、I+0.2J+0.15vv*、Jを使用する。vは位相0、0.7、1.9、−0.5 radの単位複素数ベクトルである。Jだけのモデルは独立受信機雑音が無い完全共有電圧の極限である。

時間モデルは128出力を起点とする。whiteはK=I、long averageは65 tapのbox・raw hop8、reference FFTはFFT32・channel16・固定補間位相0.25の既知係数から作る。出力局powerを1へ規格化する。boxを9出力おきに保持すると15出力、referenceを5出力おきに保持すると26出力となる。これは既知の固定係数の入力支持範囲に関するモデル条件であり、実受信機の推奨間隔ではない。

5信号×5時間モデルの25条件を各8,192反復し、seedは信号モデル順・時間モデル順に72〜96で固定する。通常の積とU₃の全三角形の実部・虚部の平均を、既知平均に対する6反復標準誤差と丸め許容値で検査する。丸め許容値は10⁻¹²×max(1,既知平均と真のbispectrumの最大絶対成分)である。基準を満たさない場合も結果JSONと図を保存して停止する。

## 式

三角形i,j,kに対して、次を置く。

```text
B = S_ij S_jk S_ki
D = S_ii |S_jk|² + S_jj |S_ki|² + S_kk |S_ij|²
P = S_ii S_jj S_kk
R = K（対角を0にした行列）
T₂ = sum_{t≠u} |K_tu|²
T₃ = trace(R³)
```

T₃は3時刻が相互に異なるcycleの和で、HermitianなKでは実数である。対角を0にして計算することで、独立時刻の極限で大きなtrace同士を引き算しない。

```text
E[U₃] = r₀³ B
       + r₀ D T₂ / [M(M−1)]
       + (P + conjugate(B)) T₃ / [M(M−1)(M−2)]
```

独立時刻ならR=0で追加項は消える。天体が無くSが対角ならD=B=0となり、段階055の受信機雑音だけの式に一致する。天体信号があるとDの項とBの共役を含む項が残る。独立した窓を増やしても、各窓の平均にあるこの項は平均化だけでは消えない。

通常の三つの平均visibilityの積も出力する。

```text
E[ordinary] = r₀³ B
            + r₀ D trace(K²) / M²
            + (P + conjugate(B)) trace(K³) / M³
```

この式はproper Gaussianの6通りの縮約から導出し、小さいMの全時刻列・全縮約の総当たりと比較する。既知S・Kの下での期待値であり、一度得たU₃の誤差や、未知の偏りを観測から補正する関数ではない。

## 結果

三角形順の真の周辺bispectrum `true_marginal_bispectrum=r₀³ B`、二つの追加項、U₃と通常の積の期待値、T₂・T₃、M、仮定・未検証事項を返す。分散・尤度は計算しない。期待値の角度も、一度測った統計の角度の期待値とは異なる。

入力はマスク無しの有限Hermitian半正定値S・K。範囲外・不一定の時間power・非有限計算・三局power積の数値underflowを拒否する。0の局共分散による0の期待値は認める。

今回の式を現行の相関器やRMLの重み・採否・観測補正へ適用しない。実FFTの依存性や局ごとの異なるKを別途検証する必要がある。
