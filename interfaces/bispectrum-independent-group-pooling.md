# 独立周波数群のU₃と電圧標本のまとめ方

この規約は既知モデルの計算専用である。実観測の周波数をまとめる機能ではない。

## 入力と二つの統計

`pooled_covariance_bispectrum_mean(S_groups, samples_per_group, triangles=None)` は1〜64群、3〜8局、各群3以上、全群合計100万以下の独立標本を仮定する。群ごとに有限・Hermitian・半正定値の局共分散Sを与え、同じ群内の基線平均は一定とする。全群の標本は相互に独立である。マスク・異なる標本数・未知共分散を受け付けない。

群ごとのU₃を等しく平均した統計と、全群の電圧標本を一つにまとめたU₃では、群をまたぐ三基線の組み合わせが異なる。

## 独立だが群ごとに基線平均が異なる場合

三角形(i,j,k)の各標本rの基線平均をa_r、b_r、c_rとする。Sの該当成分を各群の標本数Mだけ繰り返す。全標本数Nに対して、

```text
A = sum(a_r), B = sum(b_r), C = sum(c_r)
H_ab = sum(a_r b_r), H_ac = sum(a_r c_r), H_bc = sum(b_r c_r)
J = sum(a_r b_r c_r)
E[pooled U3] = (A B C - H_ab C - H_ac B - H_bc A + 2 J) / [N(N-1)(N-2)]
```

これは、全て異なる順序三つ組の期待値を独立性から計算した包含排除の式である。この平均の恒等式にはGaussian性は必要ない。局共分散の検査に既存のGaussianモデルAPIを使用するが、異なる群をまとめた統計の共分散は計算しない。

## 全群が同じSの場合の分散比較

独立proper Gaussian電圧、群数G、各群M標本で同じSを持つ場合だけ、平均したU₃の共分散はC(S,M)/G、まとめたU₃はC(S,GM)である。既存の段階059と068の式を使用する。

天体無しS=Iの複素分散では、前者と後者の比は `(GM-1)(GM-2)/[(M-1)(M-2)]`。この条件での比を天体信号がある場合や実FFTへそのまま流用しない。

## 周波数ごとの局位相が変わる例

4群・4局の `S=I+0.1J` に、群g・局iのgain `exp(2 pi i g i/4)` を掛ける。各群の三角形平均は0.001のままだが、全標本をまとめたU₃の平均は `0.002/[(4M-1)(4M-2)]` になる。独立標本だけであっても、群をまたいで局位相を混ぜることが原因である。

既知の位相変化例であり、実機のdelay・帯域gainを測定した結果ではない。群ごとの振幅gainが異なる場合は追加の影響がある。

## 制約

実FFTの周波数間独立性、周波数で変わる天体構造、局の帯域特性・時計、同じデータでの補正推定、量子化・品質選別を検証していない。分散の式はGaussianなU₃尤度や検出確率を保証せず、実観測時間へ換算しない。現行相関器・RMLは変更しない。
