# window全体の符号反転による条件付きp値

段階086の実験API。入力は実ベクトルであり、本APIは電圧・FFT・VDIFを直接処理しない。[段階087の有限電圧実験](casa-window-symmetry.md)で正規化U₃の虚部へ接続する。実観測で以下の仮定が成立するかは別途確認する。

## APIと仮定

`vsora_imaging.window_symmetry.exact_window_sign_flip_test(window_vectors)`

- 入力は有限実配列 `[Q,D]`。Q1〜12、D1〜56。行はwindow、列は同じwindowで共有される複数成分。complex、bool、masked、空配列、非有限値は拒否する。
- 計算精度はfloat64。変換でoverflowする拡張精度値や、非零成分が0へ消える入力も拒否する。範囲内の丸めとtieは後述の規約で扱う。
- 帰無仮説H0は、各行を独立に±反転しても、全体の同時分布が変わらないこと。独立で中央対称なwindowは十分条件だが、各行の周辺分布が対称なだけでは足りない。
- 一つの行の全列を一緒に反転する。三角形や列を別々に独立反転して誤差相関を壊さない。
- 入力から平均や分布をfitしない。Gaussian、共分散、真のSEFD、誤差のσは入力しない。零行も含め、入力を選別・削除しない。

## 計算と数値上の規約

全データの最大絶対成分で一度だけscaleを整える。このscaleは符号反転に不変で、零入力では割らない。全 `2^Q` 通りについて、符号付き平均ベクトルの二乗normを計算する。元のデータは全符号+1の組に含まれる。

上側p値は `元以上の統計量を持つ符号組数 / 2^Q`。tieを含む比較を保守側へ行うため、`4096 × float64のeps × 全群の最大統計量` を元の統計量から引いて数える。この係数はデータで調整しない。p値の整数比自体は二進数で表現できるが、統計量の計算は浮動小数点演算であり、実数演算が無誤差という意味の「exact」ではない。

返す主な値：

| 値 | 意味 |
|---|---|
| `upper_tail_p_value` | 条件付きの上側比率 |
| `tail_count`, `group_size` | 元以上と数えた組数、全符号組数 |
| `observed_squared_mean_norm_scaled` | 数値scaleで整えた平均二乗norm |
| `input_global_scale` | 入力の最大絶対成分。物理的雑音のσではない |
| `comparison_absolute_tolerance_scaled` | tie比較に使った丸め許容値 |
| `minimum_two_sided_resolution` | 全体符号の反転でもnormが同じになるための下限 `2/2^Q` |

零ベクトルや全統計量が同じ場合はp=1。最低でも元と全符号反転があるためp=0にはならない。Q=1ではp=1、Q=4の最小pは0.125、Q=8では0.0078125。これはこの全列挙・二乗norm統計量の分解能であり、一般的に必要な観測window数を示さない。データの縮退でさらに粗くなる場合がある。

## なぜ条件付きの誤棄却率を抑えられるか

符号反転は恒等変換・逆変換・合成を含む有限群になる。一つのデータを全群で動かした集合をorbitと呼ぶ。H0の下では、同じorbit上の観測位置を符号で特別扱いできない。統計量の順位から作る上側比率に対し、p≤αになる位置の割合はα以下で、tieは保守的に作用する。

有限群と同時分布不変性の根拠は[Hemerik & Goeman (2018), Section 2.1](https://doi.org/10.1007/s11749-017-0571-1)。本実装は全群を列挙する。ランダムな変換を一部だけ抽出する方式の式とは区別する。整数による直接列挙、固定orbitの全位置、有理数での近接tieを別途検査する。

## 解釈の限界

pはH0の仮定の下での統計量の上側比率で、Cas Aの存在確率でも画像の信頼区間でもない。仮定の正しさをp自身から証明しない。例えば全windowへ同じ対称な乱数ベクトルをコピーすると、周辺分布は対称でも同時分布は各行反転に不変でなく、この方法で小さいpが出る。

正規化U₃の虚部への接続には、共役対称性・gain/LOの時間変化・window間の相関を確認する必要がある。棄却は天体の広がりや角度上の非対称性を単独で証明しない。非棄却も点源・無信号の証明ではない。入力を見てwindowや成分を選ぶ処理、多数条件を試して最小pを報告する探索、実機・RMLへの自動適用は含まない。
