# 開発計画：実RTL-SDR/OCXOのCas A画像化へ進む

段階130の文書整理で、技術基準を129（`483a0b9`）へ統一した。目標は1.42GHz・最大基線約600m・局別周波数差・数百ms〜数秒短積分・精密gain較正困難なClosure＋RMLによる実観測画像化。Windows収録は装置に合わせて後で開発する。下の候補は実施済みではなく、正式選択時に目的・範囲・完了条件を固定する。

## 129までの到達と残る核心

CPU参照の模擬IQ→VDIF→時計/rate補正→相関→相対画像、有限区間列、日本語GUI、誤差を調べる保存情報がある。121で処理/収束/参照差をGUIへ接続した。122〜124は外部EHTimを独立に確認したが、画像比較はw=0・無雑音・人工weightの参照に限り、追加反復と主経路への置換を保留した。

125〜129は保存相関の残差、条件付き時刻分割、生成/復元格子、固定罰則を切り分けた。128の同格子・無雑音・全時刻・画像罰則なしはNRMSE約0.000318だった。一方、129の模擬電圧推定LOは既定約0.208、画像罰則なし約0.200。新9fit/27探索は収束したが、全時刻使用なので新しい未使用予測は測っていない。既定値は維持した。

この差は、実装が限定条件で計算できることと、弱い未知観測から正しい形を求めることが別であると示す。低SNR画像尤度、弱い実信号の未知LO/振幅/SEFD、実感度/FFT独立性、実機Cas A、全夜/GPUは未検証である。

## 段階134による接続順序の具体化

全体文書の技術基準129は140の定期整理まで維持し、ここに直近133/134による作業配分を追記する。132は4原本×3積分で未知LO取得・相関まで完了したが、弱.3秒は両Closure0。133は10画像/2制約不足、選択2収束/8上限、全10形状差が固定priorより大きかった。[133](../reports/133-short-integration-images.md)・[134](../reports/134-image-statistics-contract.md)を参照する。

134ではnative RMLのw項が既にあることと、042/044/046/047/049の全雑音・joint Closure・filter参照APIを確認した。132完全相関の36セルは既存047の診断前に必要な保存情報を保持する。新しい同等APIや保存producerを先に作る予定を採らず、現在のデータへの接続を優先する。これは新しい共分散算出や画像改善の実績ではない。

- **135候補**：既存APIで132の全12×8=96セルの診断状態を保存する。適用可能セルで全visibility/phase-logamp joint covarianceとproduction対角近似を同じ有効行・基底で比較。047既定SNR5とproduction SNR10を明確に分ける。PSD/数値範囲の拒否・inactive・unverifiedを残す。原本SHA・source/導入・非上書き・全JSONを照合し、IID/coverageは未検証、RMLは変更しない。
