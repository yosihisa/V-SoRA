# 現在の開発計画

## 目指す完成形

実際のRTL-SDRが記録したIQと補足情報から、時計と周波数差の補正・短積分相関・Closure＋RML画像復元を実行し、条件と結果を保存することです。Windows収録ソフトはハードウェア側の状況に合わせて後で作ります。処理の意味は[入門ガイド](../guide/README.md)を参照してください。

## 次に進める順番

1. 段階020：Closureの局誤差不変性、独立な組・共分散、積分中の周波数差を検証する。
2. Closure＋RMLの小規模参照実装。未知の利得を加えた模擬天体を、生成形状を事前画像に使わずに復元する。相対fluxと位置の自由度を明記する。
3. 天体の絶対振幅・位相を既知としない短pilotの周波数差推定。IQ補正・再相関をClosure画像化へ接続する。
4. 日本語GUIへRMLの条件選択・結果比較と収録データの入口を追加する。
5. 長時間VDIFを小さい区間で時計補正し、数百ms〜数秒の相関とClosureを蓄積する。途中失敗・再実行も記録する。
6. bandpass、低SNR統計、主ビーム差、baseline由来の誤差、実機SNR・RFIを評価する。
7. 実観測からの復元と不確かさ評価。その後、必要なGPU処理や既製ソフトとの比較へ進む。

高精度な利得較正の手段がないというユーザーの前提を採用します。段階007〜012の既知モデル較正は比較・動作検証として残します。単一積分は数百ms〜数秒を想定し、必要な短pilotと全観測時間を区別します。Closureの条件と限界は[設計](closure-rml-plan.md)を参照してください。

現在はCPUによる参照実装です。GPU搭載機でも自動的にGPUへ移る構造ではありません。正しさと処理時間を測ってから、重い処理にGPUを導入します。
