# Linux処理系の段階計画

Windows収録フロントエンドは当面対象外。最終目標は実観測IQから画像までの処理完成であり、模擬データだけで実観測成功とは判定しない。

| 段階 | 目的 | 完了条件 |
| --- | --- | --- |
| 001 | ソフト別構成、設定、参照画像 | 入力検査、単位・座標規約、匿名化した参照画像と出典を保存 |
| 002 | 理想visibilityと画像復元 | 点源・2点源の独立参照値、位置・振幅、dirty/PSF/CLEANを検証 |
| 003 | Cas Aと観測条件比較 | 局数・配置・時間・仮定感度を変え、uv・画像・定量指標を保存 |
| 004 | 模擬IQと相関 | 独立した期待相関値とFX出力を比較、形式の読み書きを検証 |
| 005以降 | 誤差補正、校正、実データ接続 | 時計・LO・欠落等を段階追加し、成功条件と未対応範囲を記録 |

最初は小規模CPU参照実装を作る。GPU最適化や既製ソフトとの互換性は正しさの確認後に進める。
