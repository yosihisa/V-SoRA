## 読者向け概要

157では、単位長さのsigned画像方向（正負の画素成分を持つ方向）を平滑化しても差が残ることを調べました。しかし、方向が分かっても、画素を負にしない範囲でどれだけ動けるかは別問題です。今回は、同じ保存方向とpriorから正の画像候補を構成し、局所微分の予測と有限のClosure変化を比べました。

**非負であることは、観測がその振幅を許すという意味ではありません。** 新しく画像を復元した段階でもありません。微分で見えにくい方向でも、有限変化では非線形の応答が現れることを、同じ支持・誤差近似のもとで記録します。

## 2. 完了条件と候補の作り方

保存priorをq、総和0・単位L2の保存方向をdとして、対称振幅上限を次で固定しました。

```text
hmax = min(q_i / abs(d_i))  （d_i != 0）
候補 = q ± fraction * hmax * d
fraction = .25, .5, .75
```

全成分の不等式から境界の一方が数値0に達し、1.01倍では負画素が出ることを確認。境界画像はAPIへ渡さず、正負6候補/入力と基準priorを評価します。候補をclip・再正規化せず、正/総和1/最小画素が少なくとも元の.25倍という条件を確認しました。既存API自身のunit-flux正規化は従来の仕様です。

32×32/16arcsec、prior FWHM240、SNR10、選択基底/有効基線/同種同cell共分散を156と完全一致に固定。entropy/TSV/centroid0で、parameter-sum penaltyを加えません。独立の全画素point Fourier（w項あり）、複素三角形積/振幅積比、共分散行列への直接solveで実APIのデータ損失を照合しました。観測支持と共分散選択を共有するため、誤差モデル自体の独立検証ではありません。

model |V|<1e−14、位相残差の±πへの距離≤1e−4はblocked/null保存とする規則を実行前固定し、fractionを縮めて回避しません。局所Jによる予測やlossの大小は合格条件にせず、記述量として全件保持します。
