# 段階003：Cas A参照モデルと局配置の初期比較

- 作成日：2026-10-02
- 状態：完了（7条件の予備評価）
- 比較元コミット：dec0206

## 1. 目的・完了条件

既存Cas A画像を天体モデルとして模擬観測し、局数・時間・配置・仮定感度による違いを同じ評価条件で比較する。良い結果だけでなく悪い結果と非収束も保存する。

## 2. 実作業

FK5→ICRSへ変換して画素の方向余弦を計算し、モデル格子へフラックス保存でbinning。200秒角領域の正の画素を採用し、総フラックス1000 Jyへ正規化。これは形状モデル化の仮定で、負の画素を採用しない影響は残る。入力FITSの旧式PCキーワードを標準化し、WCS警告を解消した。

8局は非規則2D、直線、リングを比較。各配置の最長基線は600 m。共通の仮想地点（北緯35度、東経135度）、2026-10-02T08:00:00Z開始、2.048 MHz、1.42 GHz、64×64・16秒角画素。4時間は120秒間隔の積分中央モデル、10分は60秒間隔。主ビーム・時計・校正誤差はない。

Högbom CLEANの探索領域は220秒角円、最大5000反復。画像は110秒角共通beamで比較し、260秒角内のNRMSE等を計算。復元側のフラックスを後で正規化していない。[評価規約](../../validation/plans/imaging-evaluation.md)。

## 3. 検証結果

自動検証 **24件成功**。Cas Aモデルの非負性、総フラックス、ゼロ基線、評価がフラックス誤差を隠さないことを追加確認。

| 条件 | NRMSE | 相関係数 | 成分フラックス比 | CLEAN収束 |
| --- | ---: | ---: | ---: | --- |
| 4局・10分・2D・理想 | 0.664 | 0.660 | 0.969 | yes |
| 4局・4時間・2D・理想 | 0.537 | 0.749 | 0.955 | yes |
| 8局・4時間・2D・理想 | 0.00421 | 0.99999 | 0.998 | yes |
| 8局・4時間・直線・理想 | 0.314 | 0.917 | 0.991 | yes |
| 8局・4時間・リング・理想 | 0.852 | 0.743 | 0.0566 | **no** |
| 8局・4時間・2D・SEFD 1万Jy | 0.00400 | 0.99999 | 0.998 | yes |
| 8局・4時間・2D・SEFD 100万Jy | 0.0648 | 0.99977 | 0.931 | yes |

リングの最短基線は約230 m、2Dの最短は約41 m。リングは5000反復で停止し、短基線不足と今回の復元方式で成分総和が大幅に不足。これは「リング配置でどの手法でも復元不可能」との証明ではない。

ノイズを追加したSEFD1万JyのNRMSEが理想より僅かに小さいのはseed・停止条件の差であり、雑音が改善を保証するという意味ではない。SEFD100万Jyは各局の仮定で、実受信機の測定値ではない。

## 4. 判断と限界

今回の理想条件では、短基線と2Dのuv被覆を持つ8局構成で、共通110秒角で見た形状モデルをよく再現できた。実観測の見込みを進める根拠になるが、73秒角の全構造復元や実機同期・感度を実証したものではない。

単一seed・開始時刻・CLEAN方式。真の点源位置と実機誤差がなく、主ビームや時間・帯域平均の影響もまだない。w項の200秒角内の位相は約0.0043～0.0071 radで、小視野近似が小さい条件を選んでいる。
