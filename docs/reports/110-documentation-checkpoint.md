## 読者向け概要

開発が進むと、個々の部品の詳しい記録は増えても、今どこで画像化が止まるかを見渡しにくくなる。そこで、ユーザー指定の10段階ごとの整理として、全体説明と現在の計画を同じ時点へそろえた。

最新の109では、弱い模擬データは周波数差推定で止まり、高感度の仮定でも画像最適化は未収束だった。この事実を、既知二候補の分類やGUIの充実と混ぜずに説明する。文書整理で新たな観測成功が増えるわけではない。

## 1. 目的・対象範囲

二つの工学系学部生向け全体レポート、開発計画、短い現状案内、文書入口、README、索引の基準を109までへ更新する。過去の個別レポートは当時の仮定・結果・失敗を保つ。10段階ごとの整理は次120、根本見直しは次150とする。109で分かった上流の律速に応じて、次の技術作業を具体化する。

## 2. 完了条件

1. 106〜109の経緯と、主画像経路へ優先順位を戻した理由を追加する。
2. 000〜109の初回commitとJST日付を全件照合し、旧000〜105の106行を保つ。

## 3. 実際に行った作業

[開発の時系列](overviews/development-history.md)には、106の整理、107の閾値学習、108の初回基準見直し、109の同じVDIFを使った診断へ進んだ経緯を追加した。なぜ分類APIの次のGUIを保留し、主経路へ戻ったのかを説明する。末尾のGit一覧は109までとし、自分自身のcommitを先に推測して埋めない。

[最終目標と要素別進捗](overviews/goal-and-progress.md)には、高感度の未収束と弱条件のLO推定停止の表を追加した。SEFDは仮定値、画像差は真値のある模擬実験専用、同じpilotの二つの失敗は独立な検出率測定ではないことも解説した。処理の完了・数値収束・天体形状の正しさを分ける。

[開発計画](../design/development-roadmap.md)と[短い現状案内](../guide/09-observation-readiness.md)では、次の111をpilot長・利用基線・探索条件の切り分けに具体化した。112以降の補正方針、画像側の初期値/未収束/uv合成/低SNRモデル、必要なGUIは結果次第で選ぶ。真のLOを使う対照を、未知LOの推定成功と読み替えない。ハードウェアを測れる時点では感度・時計等をモデルへ戻す。

[文書入口](../README.md)、[リポジトリREADME](../../README.md)、[段階索引](README.md)も基準をそろえた。過去の統計参照は有用な比較用部品として残し、低SNR画像尤度を既に解いたとは書かない。
