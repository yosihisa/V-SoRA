- 作成日：2026-10-02
- 状態：完了
- 比較元コミット：1dbaf99

## 1. 目的・完了条件

Windowsソフトを除く開発の土台を用意する。ソフト別の配置、共通設定の検査、単位・座標・基線符号の規約、出典を追える匿名化参照画像を整備し、確認を実行する。

## 2. 実際の作業

- `apps/{simulator,correlator,imaging,recorder}` と `packages/{observation,formats}` へ移行。旧フォルダは空ファイルのみと確認して整理。recorderは対象外のREADMEのみ。
- pyproject.tomlとソース実行用tools/run.pyを追加。既存科学計算環境をGit管理外のローカル環境から参照。
- JSON設定、座標・時刻・基線・visibility・雑音の規約、Linux開発計画を追加。
- Cas A原画像のSHA-512を検証。Jy/beamからJy/pixelへ換算した派生FITSを追加。WCSとbeamを維持し、OBSERVER、HISTORY等を省いた。
- 公開前確認スクリプトを追加。独自形式は標準互換を確認したものと区別する。

## 3. 検証条件・結果

実行環境は [Python環境記録](../design/python-environment.md)。`python tools/run.py pytest -q` で12件成功。設定の正常系、非有限値、負値、UTC欠落、分割不能な時間、座標・画素数・効率、重複ID、不明キーを検査。参照FITSのchecksum、単位、総和、匿名化ヘッダーを確認した。

参照画像の再計算した総フラックスは **1255.144689 Jy**。既存付随JSONの1295.509103 Jyとは不一致。元ファイルのSHA-512は記録と一致し、今回の換算式をJSONに保存した。元画像の114352画素が負値。派生画像では削除せず、天体モデル化時に背景・領域の扱いを指定する。

## 4. 制約・次段階

この段階は画像復元を実行していない。観測地点、局配置、感度、総フラックスは仮定。参照は1378/1750 MHzを組み合わせた2017年画像であり、現在の1.42 GHzの絶対フラックスではない。クリーン環境インストールは未検証。
