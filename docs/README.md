## 現在の説明と過去の記録

`guide/` と開発計画は、今使える処理を説明するための文書である。`reports/` の個別レポートは、各段階で何を与えて、何を実行し、どんな結果と失敗を得たかを残す記録である。過去の「次段階」は当時の計画なので、現在の順序は開発計画から読む。

全体レポートは過去の記録をつなぐ説明であり、新しい数値試験を実施した報告ではない。既知モデルの計算、有限模擬電圧の検証、実機の測定を区別する。**実受信機によるCas A画像化は未検証**である。

文献調査や容量設計には作成日と仮定がある。候補として挙げたソフト全部を導入・確認したという意味ではない。具体的な動作確認は、そのソフトを実行した段階レポートを参照する。

[150の専用根本レビュー](reports/150-fundamental-goal-review.md)で、149の後段容量拒否を防ぐ作業と、実前方平均・量子化・推定/採否の最小差へ優先順位を更新した。次の文書整理は160、予定の専用根本レビューは200。[現在の運用](design/development-governance.md)に周期と記録条件を示す。

## フォルダの役割

| 場所 | 保存するもの |
| --- | --- |
| `guide/` | 原理、用語、操作、結果の読み方 |
| `design/` | 現在の開発計画、環境、設計上の条件 |
| `literature/` | 文献と候補ソフトの調査 |

| `../interfaces/` | 時刻・単位・符号・ファイル間の契約 |
| `../validation/runs/` | 小容量の数値結果・図・公開用検証記録 |

大容量IQ・VDIF・MS、実測局位置等は公開Gitへ入れず、ローカルの原本と識別情報で管理する。開発記録とコミットの運用は[AGENTS.md](../AGENTS.md)を参照する。
