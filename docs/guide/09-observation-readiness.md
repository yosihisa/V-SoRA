# いま使える処理と、実観測へ進むための確認

2026-10-26、段階130で技術基準129（`483a0b9`）へそろえた案内です。目標はRTL-SDR/OCXO、1.42GHz、最大基線約600m、数百ms〜数秒の短積分でCas Aの形を求めることです。精密な局gain較正が難しいためClosure＋RMLを主経路にします。Windows収録は装置に合わせて後で開発します。

| 処理 | 確認した範囲 | 残ること |
| --- | --- | --- |
| IQ・VDIF・相関・FITS-IDI | 限定profile、分割CPU処理、時計/符号/単位、CASA接続の有限模擬検証 | 実RTL-SDRのI/Q、sample/UTC、sample rate、欠損・bandpass |
| 局別周波数差 | sky形状を渡さないpilot、一定/線形rate補正、graph診断 | 弱い実信号、実OCXO変動、取得失敗/誤採用/残留位相 |
| Closure＋RML | 高SNR近似、共有誤差共分散、相対画像、原本/格子/罰則の固定対照 | 低SNR画像尤度、独立データの予測、画像不確かさ |
| 日本語GUI | 模擬/VDIF/区間列/画像、同梱参照6種類、121の画像三判定と評価JSON | 125〜129の比較はworkflow/CLI。必要な検証だけ今後接続する |
| 三次統計U₃・共通電力 | 共通FFT powerのraw v2保存、無次元比、条件付き検定とGUI | 実FFT独立性、未知LO/SEFD、低SNR画像化との接続 |

実受信機からのCas A画像化は未検証です。生成した電圧を実際のVDIFファイルへ保存して処理した確認と、実装置が受信した電圧の確認は分けます。仮定SEFD、既知の時計や真値LOを実測値へ読み替えません。

## 画像を見るときの五つの判断

| 判断 | 何を意味するか | 注意点 |
| --- | --- | --- |
| 処理完了 | 画像や結果が保存された | 正しい形・数値収束とは別 |
| 数値収束 | optimizerの停止条件に達した | 大域解や画像の正しさは保証しない |
| データ適合 | 現在のモデルで残差が小さい | 雑音や事前条件、weightの近似を含む |
| 未使用予測 | fitに使わなかった値を説明する | 上流LO/mask/weightの共有、独立rawかを確認 |
| 参照形状差 | 真値のある模擬試験で形を比較する | 実画像に真値NRMSEを作り足さない |

[121のGUI](../reports/121-image-assessment-gui.md)は、処理状態・選択run収束・参照v2の有無を分けます。保存summaryは変更せずSHAを対応させて評価JSONを取得できます。参照なし・旧参照・破損・不足も成功に丸めません。

## 121〜129で何が分かったか

- 外部EHTim1.3.2と符号/Closureを照合しました。最初の画像比較はw=0・無雑音・人工weightの参照だけです。追加反復でも未収束で、主ソフトへの置換を保留しました。[122](../reports/122-ehtim-convention-bridge.md)・[123](../reports/123-paired-w0-rml-reference.md)・[124](../reports/124-ehtim-iteration-gradient-controls.md)。
- 125は保存相関を共通283基線セルへそろえ、正解D約0.554よりfitの約0.287が小さい例を確認しました。Dは共有共分散で規格化した残差二乗和を2Nで割る量で、形状の正しさやp値とは違います。[残差診断](../reports/125-closure-residual-diagnostics.md)。
- 126は偶数/奇数4時刻でfitと評価を分け、学習D約0.215〜0.240でも未使用D約5.88〜13.40となりました。同じ原本で上流情報を共有しうる条件付き分割で、独立な観測ではありません。[時刻分割](../reports/126-temporal-image-validation.md)。
- 127/128は生成天空をfitter8格子へ合わせた別の無雑音対照です。画像罰則なし・全時刻なら形状NRMSE約0.000318でしたが、半分の時刻には未使用残差が残りました。[同格子](../reports/127-matched-grid-image-control.md)・[罰則成分](../reports/128-regularizer-image-controls.md)。
- 129は固定三設定を模擬電圧由来の保存相関へ全て移し、9fit/27探索が収束しました。通常LO枝のNRMSEは既定約0.208、画像罰則なし約0.200です。全時刻使用で新しい未使用予測は測っていません。既定格子・係数は維持しました。[主経路への移送](../reports/129-main-path-regularizer-transfer.md)。

形状比較は共通110秒角・全支持領域・平行移動のみです。真値LO/理想天空は評価専用、8格子の量子化参照は元fine32の生成正解でも厳密oracleでもありません。128の良い到達を実機や主32格子の成功として扱いません。

## 誤差の道具と画像の保証は別

現在のRMLは高SNRのphase/logamp近似です。U₃の平均補正、観測power比、条件付き対称性のp値、固定二天空のGaussian参照はそれぞれの仮定を持ち、低SNR画像尤度へは未接続です。旧raw v1の共通電力不足を他標本のpowerで補いません。[保存091/092](../reports/092-bispectrum-power-gui.md)・[条件付き検定093/094](../reports/094-stored-window-symmetry-gui.md)。

Closureが相殺するのは同じ相関cellの局ごとの一定gainです。積分中の位相回転によって失った相関を自動的に戻すわけではなく、周波数差とsample整列は上流で扱います。実SEFD、主ビーム、位相安定性、RFI、実FFT独立性、全夜/GPUは未検証です。
