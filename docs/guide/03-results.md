# 画像と検証結果の読み方

## 画像は四つを見比べる

| 出力 | 意味 | 確認する点 |
| --- | --- | --- |
| dirty | 測った相関値から直接作った画像 | 天体位置、雑音、偽のピーク |
| PSF | 点源一つを観測したときの広がり | 解像度、サイドローブ、配置による偏り |
| CLEAN model | 復元法が推定した天体成分 | 成分の分布と総flux。単位はJy/pixel |
| restored | modelを表示用のbeamで広げ、残差を加えた画像 | 全体像。ただし画素を単純に足して総fluxとしない |
| residual | modelで説明できず残った信号 | 構造が残っていないか、停止条件が妥当か |

dirty/restoredはJy/beamです。「点源がbeam幅に広がって見えるときの明るさ」という単位です。modelは各画素が持つfluxなのでJy/pixelです。両者の画素の和を同じ意味で比較できません。

現在の復元画像はλ/最大投影基線による円形Gaussian beamを使っています。実際のPSFに最適な楕円を当てはめたbeamではありません。また残差のbeam面積補正をしていないため、restored画像の画素和から絶対fluxを求めないでください。

## 数値指標

画像形状の比較では、真値と復元modelを同じ110秒角beamでぼかしてから評価します。片方だけ細かい画像のままにすると、分解能の違いを誤差と取り違えるためです。

| 指標 | 読み方 | 注意 |
| --- | --- | --- |
| NRMSE | 真値との差の大きさを真値の大きさで割る。小さいほどよい | 0.02ならこの定義で差が約2%。位置・評価領域・beam条件に依存 |
| 相関係数 | 模様の似方。1に近いほど似ている | 明るさを一律に間違えても高くなることがある |
| model flux ratio | 推定成分の総flux / 真値の総flux | 1に近いほど総fluxが一致。形の正しさとは別 |
| converged | 指定した残差閾値まで下がったか | 真の天体を一意に復元したという意味ではない |
| visibility相対誤差 | 複素相関値の差を真値の大きさで割る | 画像より前の段階で時計・較正の誤りを見つける |

## 現在の主な結果と適用範囲

| 検証 | 結果 | 結果から言える範囲 |
| --- | --- | --- |
| 理想の局配置比較 | 8局・2D・4時間の条件は4局短時間より良好 | 時計・較正誤差なし、仮定した感度。最適配置の証明ではない |
| Cas Aモデル較正 | SEFD1000/10000Jyの2条件でmodel NRMSE約1.1%/2.3% | 生成と較正に同じ天体形状を使用した整合確認 |
| 既知時計のsample整列 | 連続解析波形の基線間差約0.24% | 時計を供給、1秒以下chunk。弱いCas Aから時計を求めた試験ではない |
| CASAとの接続 | 偏心1000Jy点源の位置・channel重みを維持 | 限定FITS-IDI profile。実観測画像は未確認 |
| 模擬RFI除外 | visibility誤差約996%→4.77% | 特定の連続波・パルス。全RFIの除去を保証しない |

段階012の「4時間」は観測位置の変化を置いた時刻の幅です。短いIQを16回生成しており、実露光の合計は2.048秒または16.384秒です。4時間分のIQを相関した結果として読まないでください。

Cas Aモデル較正では、古いL-band画像を「天体はおそらくこの形だろう」という事前情報にしています。同じ形でデータを作って合わせた結果は、処理の整合確認に役立ちます。ただし、未知の1.42GHzの空を独立に復元した証明にはなりません。モデルfluxの誤りを受信機利得に吸収できることも試験しました。

失敗・非収束・短すぎる較正区間も[段階レポート](../reports/README.md)に残しています。良い画像だけで判断せず、仮定と失敗条件も一緒に確認してください。
