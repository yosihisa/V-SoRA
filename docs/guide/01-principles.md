# 電圧の記録から天体画像まで

## 1. 受信機が測るのは画像ではなく電圧

アンテナに届く電波には、天体からの電波、受信機自身の雑音、地上の電波妨害が混ざります。RTL-SDRはその波形を一定間隔で測ります。一つの複素sampleはIとQという二つの実数で表し、x=I+iQと書きます。複素数にすることで、電波の振幅だけでなく位相も保持できます。

RF中心周波数1.42 GHzと、sample rate2.048 MHzは別の量です。前者は観測する電波の周波数、後者は受信機が一秒間に記録する複素sample数です。現在の模擬条件は1sample当たり8bitのIと8bitのQを使います。

## 2. 離れた局の共通成分を取り出す

局iと局jの電圧を、それぞれx_i、x_jとします。片方を複素共役にして掛け、時間平均した値をV_ijとします。

```text
V_ij = 平均[x_i × conj(x_j)]
```

これをvisibility（複素相関値）と呼びます。両局に共通する天体の信号は残り、独立した受信機雑音は平均するほど小さくなります。visibilityは一般に複素数で、振幅と位相の両方に天体の情報があります。

現在の相関器はFFTで電圧を周波数channelへ分け、その後に掛け算と平均を行います。この順番をFX相関と呼びます。周波数別に分けると、受信機の周波数差を調べたり、妨害のあるchannelだけを除外したりできます。

## 3. visibilityは天体画像のフーリエ成分

二局を結ぶベクトルを基線と呼びます。基線を天体方向に対して投影し、電波の波長を単位にしてu,v,wで表します。u,vが大きい基線は細かい構造、小さい基線は広がった構造を測ります。

天体の各成分を足した相関値は、概念的には次の式です。

```text
V(u,v,w) = Σ S_k exp[-2πi{u l_k + v m_k + w(n_k−1)}]
n_k = sqrt(1−l_k²−m_k²)
```

S_kはk番目の成分のflux（明るさ）、l_kとm_kは中心から東・北へどれだけ離れたかを表す無次元量です。小さな角度ならrad単位の角度にほぼ等しくなります。wの項は空が平面でないことを補います。

局数Nの相互基線数はN(N−1)/2です。4局なら6、8局なら28です。地球の自転で投影基線が変わるため、長い時間に異なるu,vを測ると画像を作る材料が増えます。最大距離だけでなく、短い基線と二次元に広がる配置も必要です。

1.42 GHzの波長はc/f≈0.211m。600m基線のλ/Bは約73秒角です。これは理想的な角度分解能の概算で、完成画像の品質保証ではありません。

## 4. 時計ずれと周波数ずれを補正する

| ずれ | 起こること | 必要な情報・処理 |
| --- | --- | --- |
| sample開始時刻 | 同じ電波の異なる部分を掛けてしまう | sample番号と実際のUTCの対応、時間方向の整列 |
| ADCのsample rate | 最初は合っていても、時間とともにsample位置がずれる | 実sample rateの測定、補間して同じ時刻へ合わせる |
| LOの周波数 | 相関の位相が時間とともに回り、長く平均すると消える | 回転速度の推定、電圧の位相を戻して再相関 |
| 幾何的な到着時間 | 天体・局位置・地球自転により到着時間が変わる | 幾何delayモデルとRF位相の補正 |
| 利得・ケーブル等 | 振幅や位相が局ごとに変わる | 既知天体や共通基準を使う較正 |

GPSDOで周波数を安定させても、どのsampleがPPSの瞬間に対応するかは別に測る必要があります。USBでPCに届いた時刻を、電波を測った時刻と同一視できません。

周波数差Δrを残してT秒平均すると、単純な一定差の場合の相関振幅はおおよそ|sin(πΔrT)/(πΔrT)|倍になります。平均して消えた情報を、後から相関値だけで完全に戻すことはできません。短い積分で差を推定し、IQを補正して再相関します。

## 5. 較正と画像復元

実際の相関値は、理想値Vに局ごとの複素利得g_i、g_jが掛かった値として扱います。

```text
測定値 ≈ g_i × conj(g_j) × V
```

較正はgを推定して取り除く処理です。既知の明るさを基準にしない場合、天体を明るくしたことと受信機の利得を大きくしたことを区別できません。Cas Aは広がった天体なので、全基線を同じ1000Jyと置く点源較正は適切ではありません。

測れていないu,vが多いため、単に逆フーリエ変換したdirty画像には偽の広がりやサイドローブが出ます。CLEANは、その広がりを点源応答で説明しながら天体成分を少しずつ推定する方法です。結果を比較するときは、成分の総flux、残差、停止条件も調べます。[結果の読み方](03-results.md)へ進んでください。
