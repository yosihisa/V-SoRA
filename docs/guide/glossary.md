# 用語集

| 用語 | 意味 |
| --- | --- |
| Cas A | Cassiopeia A。今回画像化を目指す超新星残骸 |
| RTL-SDR | 電波を受け、I/Qのsample列としてPCへ送る受信機 |
| OCXO | 温度を一定に保って発振周波数を安定させる基準発振器 |
| GPSDO | GNSSの基準に合わせて周波数を制御する発振器 |
| PPS | 通常は毎秒の境界を知らせるpulse。sampleとの対応は別に測る |
| ADC | アナログの波形を数値sampleへ変える装置 |
| LO | 受信RFを低い周波数へ変換するための局部発振器 |
| IQ | 位相を保持する二つの成分IとQ。x=I+iQと表す |
| sample rate / FS | 一秒当たりに記録する複素sample数 |
| RF | アンテナに入る電波の周波数。1.42GHzはRF中心 |
| baseband | RF中心からの周波数差を表す受信後の帯域 |
| station / 局 | アンテナ・受信機・記録機を置く観測拠点 |
| baseline / 基線 | 二局の位置を結ぶベクトル |
| ENU / ECEF | 東北上の局所座標 / 地球中心固定の三次元座標 |
| ICRS / FK5 J2000 | 天体位置を表す座標の基準。混同せず変換する |
| phase center / 位相中心 | 到着時間や位相を合わせる基準の天体方向 |
| u,v,w | 基線を位相中心に対して投影した座標。ここでは波長単位 |
| visibility | 二局の電圧の複素相関値。画像のフーリエ成分に対応 |
| FFT / FX | 高速フーリエ変換 / FFT後に相互乗算する相関方式 |
| integration / 積分 | 一定区間の相関値を平均する処理、またはその区間 |
| frame / shard | VDIFの小さな記録単位 / 相関出力を分割したファイル |
| VDIF | 局・時刻等を付けた電圧sampleの交換形式 |
| FITS-IDI / MS | 干渉計の相関値を保存するFITS形式 / CASA等が使う作業形式 |
| NPZ / manifest | NumPy配列の保存形式 / 入力ファイルと処理条件の一覧 |
| Jy / flux | 電波の明るさを表す単位 / 対象成分の明るさ。1Jy=10^-26 W m^-2 Hz^-1 |
| SEFD | 受信機雑音と同程度になる天体flux。大きいほど感度が低い |
| gain / 複素利得 | 受信機が信号へ掛ける振幅と位相の変化 |
| delay / rate | 位相の周波数方向の傾きに対応する遅延 / 位相が時間に対して回る速度 |
| fringe / coherence | 相関の位相やその縞 / 位相が揃い、平均しても信号が残る度合い |
| calibration / 較正 | 基準の天体や信号から受信機応答を求め、取り除くこと |
| prior / self-calibration | 事前に置く天体情報 / 天体モデルを使って受信機応答も調整する較正 |
| bandpass / primary beam | 周波数別の受信応答 / アンテナの方向別の感度 |
| RFI / flag | 天体以外の電波妨害 / 無効または除外とする印 |
| SK | FFT powerの変動を調べるspectral kurtosis。複素Gaussian雑音の期待値は1 |
| weight / sigma | 統計的な重み / 雑音の標準偏差。ここでは重み=1/sigma² |
| dirty / PSF | 直接作った未補正の画像 / 点源を観測したときの画像応答 |
| CLEAN / residual | 点源応答を使い成分を推定する復元法 / 説明できず残った信号 |
| restored / beam | 成分を表示用の幅へ広げた復元画像 / 点源の広がり・表示分解能 |
| snapshot / pilot | 短い時刻区間を固定した模擬観測 / 較正を求めるための短い観測区間 |
| alias | 異なる遅延や速度が同じ測定値に見える曖昧さ |
| closure / spanning tree | 局応答の影響が消える基線組合せ / 全局を検出基線で結ぶ木構造 |
| IERS / EOP | 地球の回転等を提供する機関 / その補正に使う地球姿勢の値 |
| regression / wheel | 過去に動いた機能を再確認する試験 / Python配布用パッケージ |

数式との関係は[原理](01-principles.md)、指標の読み方は[結果](03-results.md)を参照してください。
