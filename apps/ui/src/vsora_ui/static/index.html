SIMULATION

模擬観測から画像を作る

正解がわかっている天体を使い、局の配置・観測時間・雑音による違いを調べます。

観測条件

仮想観測

観測時間は積分時間の整数倍にします。長く観測すると投影基線が変化し、測る空間周波数が増えます。

SEFDが大きいほど感度が低くなります。ここでの値は仮定です。

固定条件と再現条件

RF 1.42 GHz、帯域2.048 MHz、最大基線600 m。仮想地点は北緯35°・東経135°。開始UTCは2026-10-02 08:00、画像は64×64・16秒角/画素です。

この処理で確かめること

  1. 正解の空を用意点源や参照画像から、明るさと位置を決めます。
  2. 相関値を生成局の配置と地球自転から、測れるフーリエ成分を計算します。
  3. 画像を復元・比較dirty画像とCLEAN結果を表示し、正解との差を測ります。

結果の適用範囲

この画面はCLEAN比較用の理想visibilityです。長い積分設定は理想条件の比較に限ります。実観測は数百ms〜数秒の積分とClosure＋RMLを想定します。時計・LO・較正の誤差は動作検証で確認します。Cas Aの参照形状と1000 Jyの設定は、実観測を保証する値ではありません。

CLOSURE IMAGING

未知の局利得から形状を復元する

短い積分のClosureを使い、相対的な明るさの画像をRMLで探します。

模擬観測とRMLの条件

連続収録のシミュレーションではありません。16個×0.3秒なら実際に使う露光は4.8秒です。全体の時間は投影基線の変化を決めます。

事前条件と探索

未知の受信機応答を加える

時刻ごとに局の振幅・位相を大きく変えます。RMLには正解画像も局利得も渡しません。一般的なGaussian事前画像から探索します。

基線SNR10以上、独立なClosureと共分散を使うCPU参照実装です。画像は32×32、16秒角/画素です。

結果の基準と制限

総相対fluxを1にします。絶対Jyや絶対位置の測定ではありません。模擬正解との比較では位置合わせの量を記録します。LOとsample時計は補正済みの仮定です。事前条件・局所解・低SNRの影響を比較してください。

VALIDATION

動作検証を実行する

正解がわかる入力で、重要な補正や検出が成立するかを確認します。実行条件と結果は履歴に残ります。

検証項目

雑音・妨害の検証は、有限の模擬条件での誤flag数と相関誤差を確認します。実環境の検出率は別に測定する必要があります。

OBSERVATION INPUT

VDIFから短区間の相対画像を作る

観測条件とsample時計の情報を入力し、周波数差の推定・再相関・Closure＋RMLを実行します。

WSL側にある観測ファイル

起動した作業フォルダからの相対パス、またはWSLの絶対パスを指定します。ブラウザへ大容量VDIFを送る必要はありません。

画像の積分全体をpilotで覆います。0.25ms × 4096個なら1.024秒、時間Nyquistは2000Hzです。FFT長とVDIFフレームに合う刻みを指定します。

探索上限は各局の差ではなく基線の最大周波数差です。Nyquistを超える初期差は別の値に折り返して見える可能性があります。短いpilotでは電波妨害のSK判定ができない場合があります。

RMLの事前条件と探索

線形モデルは4部分の測定から傾きを求め、平均前のIQへ補正します。高速な位相揺れや実機の安定性を保証する指定ではありません。

変動検出や未判定なら画像化前に停止します。未指定でも診断は記録します。整合していても速い位相揺れやcoherenceは保証できません。

必要な観測情報

局位置・天体方向・RF設定・sampleとUTCの対応・実sample rate・無効区間が必要です。既知の天体fluxや局の利得を入力する必要はありません。

source.modelをunknownとした観測設定は、総fluxを省略できます。原本VDIFのSHA-256と条件を結果に残します。

現在の処理範囲

sample時計は入力した線形モデルを使います。自動で未知時計を復元するものではありません。3秒以内・600m以下の短区間参照処理で、画像化は一つの積分です。別時刻の短露光は「合成画像」でまとめられます。3秒積分には全体を覆うpilotが必要です。実機の安定時間は未測定です。

ADC²をJyとせず、総相対fluxを1にします。実装置のCas A画像化は未検証です。失敗は途中結果として履歴に残ります。

SENSITIVITY

短い積分でClosureを測れるか見積もる

アンテナと雑音の仮定から、Cas Aの相関SNRと画像化に使える情報数を計算します。

仮定する観測条件

雑音温度には受信機・空・地面・給電損失の寄与を含めます。直径を使う指定では直接面積欄は使いません。

計算の読み方

4時間に分散する16個の短露光、最大基線600mの仮定です。局gainとLO・時計は露光内で安定・補正済みとします。

総fluxより長い基線の相関fluxは小さくなります。SNR10以上の基線から作れる独立phase/amplitude Closureを数えます。局間のgain較正をした値ではありません。

実測と分けて使う

情報数は雑音を引く前の期待値です。画像化・rate推定の成功確率ではありません。実機SEFDと位相の安定時間は測定が必要です。

帯域は一つのClosure channelで足し合わせられる幅です。別channelを複素平均できると仮定しないでください。現在のVDIF試験は256kHz幅を使います。

APERTURE SYNTHESIS

別時刻の短露光から画像を合成する

一回ごとの積分を短く保ち、時間とともに変わる投影基線の情報をRMLへ集めます。

周波数差を補正した相関ファイル

2〜32ファイル。WSL側のパスを指定します。局・周波数・単位等が同じで、重複しない露光を選びます。相関値を先に複素平均しません。

RMLの事前条件と探索

長い観測時間と短い積分

各短露光の局gainは異なっていても、時刻とchannelごとのClosureで消します。複素相関を長く平均する必要はありません。

sample/幾何整列済みの出力を使います。原本の識別情報、露光、flag、周波数は保持し、時刻をUTCへ合わせて並べます。

使える情報を確認する

低SNRではClosure phaseやamplitudeが作れない場合があります。測定数・探索の停止・事前条件依存を確認してください。描画された画像だけで復元成功とは判断できません。

結果は総相対flux1です。データを選ぶ量には直接Fourier参照実装のメモリ上限があります。

GUIDE

使い方と結果の読み方

まず点源で試す

「模擬観測」で点源を選び、そのまま開始します。処理が終わると実行履歴に画像と数値が表示されます。点源では、位置と明るさが正しく戻るかを見ます。その後、Cas A・局数・配置・雑音を変えて比較できます。

画像の違い

dirtyは相関値から直接作る画像、PSFは点源の応答、CLEAN modelは推定した天体成分、restoredは成分を表示用のbeamへ広げた画像です。modelはJy/pixel、dirty/restoredはJy/beamなので、画素の和を同じ意味で比べられません。

数値を確認する

NRMSEは正解との差の大きさで、小さいほどよい値です。相関係数は模様の似方、flux比は総明るさの一致を表します。比較では両画像を同じ110秒角beamに揃えます。CLEANの収束と天体の正しさは別に確認します。

途中で中止した場合

履歴の中止ボタンで処理を止められます。中止・失敗した入力と途中結果は残し、完了と区別します。条件を変えて再実行すると、別の実行として保存します。

Closure＋RML

未知の局利得を消した情報から、総相対fluxが1の非負画像を復元します。結果のχ²、初期値ごとの目的関数、位置合わせ前後の誤差を比べます。最適化の停止は天体形状の正しさを保証しません。

実観測に向けて

VDIFに加え、sampleとUTCの対応、実sample rate、RF・局位置・偏波・欠損情報が必要です。生ADC値をそのままJyとしません。実際のRTL-SDRでCas Aを画像化する検証はこれからです。
