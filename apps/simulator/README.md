# シミュレーター

観測条件と天体モデルから、正解がわかっている模擬データを作ります。画像からvisibility（複素相関値）を直接作る方式と、各局のIQを作って相関器も通す方式があります。

直接生成は局配置・観測時間の比較に向きます。IQ生成は量子化、時計差、相関処理の試験に使います。短い静止区間のIQ生成で長時間の実観測を再現したとは扱いません。
